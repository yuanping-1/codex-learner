## 恢复失败：已知事实与待区分原因

源码中 ZIP、解包输入输出、哈希流、课程读取均在发布前通过上下文管理器关闭。发布时持有的 `.library.lock` 位于移动子树外；释放操作的课程锁已在返回前关闭。没有找到可以确认的产品流泄漏，因此没有改动目录发布机制、添加等待或自动重试。

| 候选原因 | 现有证据边界 | 下一项区分性观测 |
| --- | --- | --- |
| 产品仍持有相关资源 | 显式流已关闭；未枚举所有原生句柄 | 失败时采集当前进程已观测且未关闭的 Python 流，覆盖外仍为 UNKNOWN |
| 目标目录出现或路径重解析 | 事前/事后记录不等于失败时状态 | 在原 rename 抛错后、回滚前采源、目标及父目录 lstat/属性 |
| 对象删除权限或共享模式不允许 rename | 读写和解包成功不证明删除权限；旧 ACL 多为事后 | 可选只读 ACL，与原错分别记录，不修改权限 |
| 外部进程或过滤驱动瞬时干预 | 没有占用者或驱动证据 | 如轻量采集不足，另行取得有权限的系统观察；不将空列表判为无占用 |

Python 3.12.10 的 `Path.rename` 经 `os.rename` 调用 Windows `MoveFileExW(..., 0)`。[MoveFileExW 官方语义](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw) 与 [CreateFileW 共享模式](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew) 支持检查删除权限和共享模式，但不能仅凭 WinError 5 定位原因。`os.replace` 也不提供绕过拒绝访问的依据。

不使用 Restart Manager 的目录查询作为占用证据：[RmGetList](https://learn.microsoft.com/en-us/windows/win32/api/restartmanager/nf-restartmanager-rmgetlist) 明确登记目录路径会返回错误 5。Sysinternals Handle 需要管理员，psutil 的 Windows 普通文件枚举不完整且不涵盖目录句柄；本轮工具不自动提权。

新增 `scripts/restore_probe.py`，仅由开发诊断驱动显式启用，产品 CLI 不导入它。实际 rename 失败后采集可读状态，然后原样抛出同一异常，继续原有回滚。记录采集自身错误、UTC、路径属性及有限流信息；外部占用者/锁拥有者保持 UNKNOWN。默认不运行 ACL 子进程，可显式开启限时只读查询。探针会改变时序、延长回滚前窗口，因此与无探针首调样本分开。

新增 `scripts/benchmark_restore.py` 固定两份旧合成归档身份，建立新目录、独立 worker，保留首次失败。提供无探针首调、旧 S05 同进程故障链及独立诊断三种模式；成功需实际核文件、传递引用、展开正文和离线读回。它验证隔离安装的 Python API，不声称验证 CLI 配置解析、原生宿主或真实 Drive。

故障测试增加注入点命中检查及完整错误信息，防止较早失败只留下错误码差异；新增清理/lstat 双故障下 `stage_exists=null` 的回归，后续存在性不改写故障时的未知状态。

## 性能：可定位的重复工作与修改

旧本机 8 个诊断样本协议完整，但不是正式分位数。候选带探针 submit 为 7.078 秒，历史完整性阶段为 6.588708 秒。4,206 份引用分别执行根目录和完整文件路径 resolve，共 8,412 次；该阶段路径安全包含计时 3.587585 秒、读取 1.858238 秒。SHA 更新 0.004869 秒、JSON 解析 0.029293 秒，现有数据不支持优先优化这两项。嵌套计时不能相加，读取不等于物理磁盘 I/O。

本轮局部修改 `blobs.py`：

1. 每份引用仍解析课程根目录，并逐一 lstat 原始路径分段；去除同一路径的第二次完整 resolve。
2. 分段检查先拒绝绝对路径、导航/空段、Windows 驱动/ADS 写法、保留设备名、尾随点/空格；各组件拒绝符号链接及 Windows reparse point。
3. 读取时合并重复的 `is_file` / `stat` 查询。每次写入仍重新校验全部正文实际字节、长度、哈希及传递引用；没有跨事务正文或祖先缓存，也没有修改原答编码、换行、去重语义或读取块大小。

兼容取舍：课程内所有 reparse point 现在均拒绝，包括过去可能解析到根内的 junction；非常规手工路径（如尾点文件名）也拒绝。正常生成的课程路径不依赖这些写法，活跃库仍要求普通本地磁盘。该修改不声称提供能抵御任意并发恶意文件系统替换的原子沙箱；既有锁与信任边界不变。

`benchmark_history.py` 补充进程及 worker 的 UTC 起止、PID、操作区间；失败保留原输出和 worker 时间记录。正式测量与有探针诊断继续分开，父进程等待子进程不算并行。
