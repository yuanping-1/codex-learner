# Codex Learner 0.2.0 验收候选

代码覆盖紧凑存储、显式迁移、逐页 OCR、四项学习功能修补、Drive 归档恢复及安装诊断。**完整交付验收仍为 PARTIAL**：本页区分云端自动化、真实模型执行、Windows CI 与用户本机/真实云盘证据。旧版 0.1.0 的本机结果不计入新包验收。

## 已实现与验证范围

| 范围 | 已验证内容 |

| 存储与迁移 | schema 2 不可变正文、按需读取、回执共用正文、CRLF/Unicode 原答逐字一致、操作去重；schema 1 只读、预览/哈希绑定迁移、旧字节备份与 legacy 核验声明保留 |
| 写入恢复 | 失败替换和回读、缺失/损坏正文、错配回执、最后有效备份保护、待评价跨进程恢复、并发写入与解析中禁止释放 |

云端 Linux 完整核心测试 140 项（138 通过，2 项 Windows 专用测试跳过），浏览器测试 18 项全部通过；最终归档字段补充后定向 22 项再次通过。命令见 [自动化测试记录](evidence/v0.2/test-summary.json)；浏览器测试使用 `window.openai` 模拟对象，不代表真实 Codex 客户端。

## 实测资源

全部数值来自隔离的云端 Linux Python 进程。RSS/工作集与 Windows Job Object 提交内存是不同指标。Codex 客户端和 Google Drive 客户端未测，不合并到 OCR 数字中。

| 测试 | 实测结果 |
|---|---|
| 固定记录数、扩大历史正文 | 正文约 24 KB → 128 MiB，清单仅约 +0.152%；list/review 峰值 12.875 MiB；大正文库短新作答约 15.137 MiB |
| 大量历史 | 1000 作答、1000 评价、1000 帮助事件、20 来源、20 讲义版本、2082 回执；list/review/history 约 30.6–30.9 MiB；submit 约 51.09 MiB |
| 大型 schema 1 迁移 | 72.02 MiB 旧 JSON → 27,895 bytes 清单；增量预览/迁移峰值均约 37.879 MiB，原答与旧备份哈希保持 |
| OCR 10 页 | 578.64 MiB，约 12.86 秒 |
| OCR 100 页 | 594.80 MiB，约 104.18 秒；峰值较 10 页增加约 2.79% |
| 三个连续 PDF | 每次约 458–479 MiB；所有 worker 均确认退出，没有残留已观察进程 |
| 原 PDF 局部重读 | 300 DPI 请求在像素约束下重新渲染，约 561 MiB，保留原坐标；结果仍待视觉核对 |

OCR 测试使用自行编写的中英数字扫描页；10/100 页使用重复同类页检验资源规模，不是复杂文档识别准确率基准。2 GiB 是默认工程预算，不能据此承诺所有 Docling 模型可运行。

写入前会流式核验历史附件以保护最后有效备份，因此写入时间随历史字节数增加。大正文样本中短新作答约 0.147 秒；大量历史样本约 1.385 秒。这些是单次样本，不能作为吞吐量或时延分位数承诺。

## 尚未取得的交付证据

1. **真实 Codex 客户端完整教学**：两章真实教学、六类答案评价、原生发送失败恢复与新独立聊天恢复待评价。本轮有业务/模拟面板/跨进程测试，不能替代真实客户端结果。
2. **真实 Google Drive 上传与网页重新下载**：本轮只验证临时目录中的完整协议。程序保留 `sync_unconfirmed` 和 `network_provenance=user_declared` 区别，未声称自动观察到了云端传输。
3. **用户本机干净安装和旧版升级**：自动化 Windows CI 与真实用户本机分别记录；新包须在目标 Codex 环境核对安装清单/包哈希并复验。
4. **可选 Docling 模型推理**：预览、选页、离线模型门控、进程预算与错误处理已实现；完整模型未实际运行。预览图受像素限制，不代表 Docling 内部所有布局分配都受同样像素限制。
5. **整机资源**：Codex、Drive 和用户本机整体占用未实测。无 OCR 配置时的 native PDF 解析有输入/提取限额，不宣称第三方解析器内部是 256 MiB 硬隔离。

## 最终包证据

发布包的 `BUILD.json` 保存版本、来源提交、读取/写入 schema 和源文件清单哈希；`MANIFEST.sha256.json` 逐文件校验。包外的 `release-verification.json` 绑定最终 ZIP SHA-256、测试结果和本页证据文件哈希，避免把另一版本测试结果当成该包验收。

安装包不内嵌模型、课程、凭据或用户配置。`scripts/package.py` 在源文件变化时拒绝发布不一致包。详情和操作步骤见 [升级说明](v0.2-upgrade.md)。
